Plain

A text editor that writes no editor code. Open a file, type, done. Mac, iPhone, iPad, and a command line.

Source on GitHub Why

They don't make them like Sublime anymore

Editors today are a div soup, a browser in a trench coat, or a subscription. Every one of them redraws the cursor by hand.

A text file is a string. Opening, saving, undo, selection, scrolling, dictation, VoiceOver: the OS already does all of that better than any JavaScript will. Plain is that idea taken all the way. No web view. No rendering layer. Nothing between you and the file.

What it looks like

From the command line

One binary. It opens a file in the app, or counts it.

plain notes.txt          open in Plain
plain stat notes.txt     3 lines, 12 words, 71 chars
cat x | plain stat       counts from stdin

Everywhere you are

Mac

Tabs, Open Recent, versions, autosave. All from the document system.

iPhone & iPad

Any file in the Files app or iCloud Drive. Split view on iPad.

Terminal

Build it with one swiftc line. No package manager, no runtime.

No accounts, no network

Plain never talks to a server. There is nothing to sign into and nothing to collect. Your file is the only thing on disk.
